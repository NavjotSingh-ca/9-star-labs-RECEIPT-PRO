# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Leduc Receipt Pro, please report it privately.

**Please** file a GitHub issue for non-critical vulnerabilities, or email the maintainer directly if the issue is sensitive.

You should receive a response within 48 hours.

### What to include
- Type of issue (XSS, SQL injection, auth bypass, etc.)
- Steps to reproduce
- Affected version(s)
- Any proof-of-concept code (if available)

## Responsible Disclosure

We follow a 90-day disclosure window. We'll acknowledge your report, work on a fix, and coordinate the release. You'll be credited in the release notes unless you prefer anonymity.

## Scope
This policy applies to the Leduc Receipt Pro application and its dependencies. It does not apply to third-party services (Supabase, Stripe, Google, Resend) — report issues to those vendors directly.

## Supported Versions
Only the latest commit on the `main` branch receives security patches.
